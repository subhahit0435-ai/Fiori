1GitHub Gist — Shared Storage Setup
Configure two private GitHub Gists as the shared repository. All end users will read SAP data from the same Gist regardless of which machine they use.
⚠️ First-time setup instructions
  • Create a GitHub account (free) at github.com if you don't have one.
  • Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  • Create two PATs: one Admin PAT (full gist read+write) and one Audit PAT (gist read+write, for end users to append audit entries).
  • Scope: select Gists: read and write for both. Set expiry to at least 1 year.
  • The Admin PAT is only stored in your browser session tab — it is cleared when you close the tab.
  • The Audit PAT is stored in the shared Gist config so end users can write audit entries without needing GitHub accounts.
